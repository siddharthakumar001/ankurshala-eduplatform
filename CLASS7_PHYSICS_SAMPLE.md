## ✅ What Gets Created in Database:

For each row, the system creates:
- **1 Board:** CBSE (if not exists)
- **1 Grade:** Class 7 (if not exists)
- **1 Subject:** Physics (if not exists)
- **1 Chapter:** Heat/Light/Motion/Electric Current (if not exists)
- **1 or more Topics:** With all AI integration fields populated:
  - `title` - from Topics column
  - `description` - from Brief Description
  - `summary` - first 200 chars of Brief Description
  - `suggested_topics` - from Suggested Topics column
  - `expected_time_mins` - Duration converted to minutes
  - `code` - auto-generated (e.g., PHY_HEA_SOURC)
